22  Autoregressive Language Models

Next-token prediction, likelihood, and mathematical generation

This chapter begins the part of the book on large language models. The goal is to explain an autoregressive language model as a clean mathematical object: a conditional probability model for the next token. Once this viewpoint is clear, training, perplexity, temperature, top-\(k\) sampling, nucleus sampling, greedy decoding, and beam search become consequences of probability and optimization rather than mysterious engineering tricks.

22.1 Learning goals

After studying this chapter, you should be able to:

  • Write the probability of a token sequence using the autoregressive chain rule.
  • Explain next-token prediction as conditional distribution estimation.
  • Derive the negative log-likelihood and cross-entropy objective for language modeling.
  • Compute sentence log-probability and perplexity from next-token probabilities.
  • Compare greedy decoding, sampling, temperature scaling, top-\(k\) sampling, nucleus sampling, and beam search.
  • Explain why causal masking is required in decoder-only Transformer language models.
  • Implement a small autoregressive generator and decoding methods from scratch in Python.

22.2 17.1 The basic object: a distribution on sequences

Let \(V\) be a finite vocabulary with \(|V|=d\). A token sequence of length \(T\) is

\[ w_{1:T} = (w_1,w_2,\ldots,w_T) \in V^T. \]

A language model assigns probabilities to sequences. For a fixed length \(T\), this means a probability mass function

\[ P(w_{1:T}), \qquad w_{1:T} \in V^T, \]

satisfying

\[ P(w_{1:T}) \geq 0, \qquad \sum_{w_{1:T} \in V^T} P(w_{1:T}) = 1. \]

The space \(V^T\) has size \(d^T\), so directly specifying \(P\) is impossible except for tiny vocabularies and tiny lengths. The central mathematical idea is to factor the joint distribution into conditional distributions.

By the chain rule of probability,

\[ P(w_{1:T}) = P(w_1)P(w_2 \mid w_1)P(w_3 \mid w_{1:2})\cdots P(w_T \mid w_{1:T-1}). \]

Equivalently,

\[ P(w_{1:T}) = \prod_{t=1}^{T} P(w_t \mid w_{<t}), \]

where \(w_{<t}=(w_1,\ldots,w_{t-1})\). This identity is exact. An autoregressive language model is a parameterized approximation of these conditional probabilities.

NoteAutoregressive viewpoint

An autoregressive language model estimates

\[ p_\theta(w_t \mid w_{<t}) \]

for each position \(t\). The model then defines a sequence distribution by

\[ p_\theta(w_{1:T}) = \prod_{t=1}^{T} p_\theta(w_t \mid w_{<t}). \]

The word autoregressive means that the model generates each new token using previously generated tokens as input. In time series notation, the future is predicted from the past. In NLP notation, the next token is predicted from the prefix.

22.3 17.2 Prefixes, contexts, and conditional distributions

For every prefix \(c=w_{<t}\), an autoregressive model outputs a probability vector

\[ p_\theta(\cdot \mid c) \in \Delta^{d-1}, \]

where

\[ \Delta^{d-1} = \left\{p\in R^d: p_j\geq 0,\; \sum_{j=1}^d p_j=1\right\} \]

is the probability simplex. If the vocabulary is ordered as

\[ V=\{v_1,\ldots,v_d\}, \]

then the model output is

\[ p_\theta(\cdot \mid c) = \left(p_\theta(v_1\mid c),\ldots,p_\theta(v_d\mid c)\right). \]

A neural language model usually produces real-valued logits

\[ z_\theta(c) \in R^d, \]

and converts them to probabilities by the softmax map

\[ p_\theta(v_j\mid c) = \frac{\exp(z_j(c))}{\sum_{\ell=1}^{d}\exp(z_\ell(c))}. \]

The logits are scores. The softmax turns scores into a categorical distribution.

ImportantRepresentation, model, and probability

For a prefix \(c\), a modern neural language model usually has the form

\[ c \longmapsto h_\theta(c) \in R^m \longmapsto z_\theta(c)=Wh_\theta(c)+b \in R^d \longmapsto p_\theta(\cdot\mid c)=\operatorname{softmax}(z_\theta(c)). \]

The representation \(h_\theta(c)\) is not itself a probability distribution. The probability distribution appears after the output logits are transformed by softmax.

22.4 17.3 Training data and maximum likelihood

Suppose the training corpus consists of token sequences

\[ D=\{w^{(i)}_{1:T_i}: i=1,\ldots,n\}. \]

The likelihood of the data under an autoregressive model is

\[ L(\theta;D) = \prod_{i=1}^{n}\prod_{t=1}^{T_i} p_\theta\left(w_t^{(i)} \mid w_{<t}^{(i)}\right). \]

The log-likelihood is

\[ \ell(\theta;D) = \sum_{i=1}^{n}\sum_{t=1}^{T_i} \log p_\theta\left(w_t^{(i)} \mid w_{<t}^{(i)}\right). \]

Training usually minimizes the negative log-likelihood,

\[ \mathcal L(\theta) = - \sum_{i=1}^{n}\sum_{t=1}^{T_i} \log p_\theta\left(w_t^{(i)} \mid w_{<t}^{(i)}\right). \]

This is also the sum of cross-entropy losses. At each position \(t\), the target is the one-hot vector for the observed next token. If \(y_t\) is the index of \(w_t\), then the one-position loss is

\[ \ell_t(\theta)=-\log p_\theta(y_t\mid w_{<t}). \]

For logits \(z\in R^d\) and target class \(y\), the gradient of the softmax cross-entropy is

\[ \frac{\partial}{\partial z_j}\left[-\log \operatorname{softmax}(z)_y\right] = \operatorname{softmax}(z)_j - 1\{j=y\}. \]

This simple formula is one reason next-token prediction scales well computationally.

22.5 17.4 Teacher forcing

During training, the model is given the true prefix from the corpus. For example, from the sentence

language models predict the next token

we form training pairs:

prefix: language                 target: models
prefix: language models          target: predict
prefix: language models predict  target: the

This training approach is called teacher forcing. The model learns from correct prefixes even though, at generation time, it must condition on tokens that it generated itself.

Mathematically, training minimizes empirical conditional cross-entropy under the empirical distribution of true prefixes. Generation samples from the model distribution over its own prefixes. This mismatch is one source of error accumulation in generated text.

22.6 17.5 Sentence probability, average loss, and perplexity

For one sequence \(w_{1:T}\), the model log-probability is

\[ \log p_\theta(w_{1:T}) = \sum_{t=1}^{T}\log p_\theta(w_t\mid w_{<t}). \]

The average negative log-likelihood per token is

\[ \bar{\mathcal L} = - \frac{1}{T} \sum_{t=1}^{T}\log p_\theta(w_t\mid w_{<t}). \]

The perplexity is

\[ \operatorname{PPL} = \exp(\bar{\mathcal L}). \]

Perplexity can be interpreted as an effective average number of plausible next-token choices. Lower perplexity usually means the model assigns higher probability to the observed text, but perplexity is not a complete measure of usefulness or truthfulness.

WarningPerplexity is not understanding

A model can have low perplexity on a dataset by learning strong statistical regularities. This does not imply that it reasons correctly, uses facts reliably, or understands meaning in a human sense. Perplexity is a likelihood-based metric, not a complete evaluation of language behavior.

22.7 17.6 Decoder-only Transformers as autoregressive models

A decoder-only Transformer represents the prefix \(w_{<t}\) using a stack of causal self-attention blocks. If the input sequence is

\[ w_{1:T}, \]

then each position \(t\) produces a hidden vector \(h_t\in R^m\). The output logits for the next token are often computed by

\[ z_t = Wh_t + b \in R^d, \]

and the next-token distribution is

\[ p_\theta(w_{t+1}=v_j\mid w_{1:t}) = \frac{\exp((z_t)_j)}{\sum_{\ell=1}^{d}\exp((z_t)_\ell)}. \]

The causal mask ensures that the hidden vector at position \(t\) cannot use tokens from positions greater than \(t\). Without causal masking, a language model trained to predict the next token could leak information from the future.

For a sequence length \(T\), the causal attention mask has entries

\[ M_{ij}= \begin{cases} 0, & j\leq i,\\ -\infty, & j>i. \end{cases} \]

The attention weights are computed as

\[ A=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}+M\right), \]

where the softmax is applied row by row.

22.8 17.7 Generation as repeated sampling

Once a model produces \(p_\theta(\cdot\mid c)\), generation repeats three steps:

  1. Compute logits \(z_\theta(c)\) for the current context \(c\).
  2. Convert logits to a probability distribution, possibly modified by a decoding rule.
  3. Choose the next token and append it to the context.

This gives a recursive stochastic process:

\[ W_t \sim p_\theta(\cdot\mid W_{<t}), \qquad t=1,2,\ldots. \]

Different decoding rules define different stochastic or deterministic processes.

22.9 17.8 Greedy decoding

Greedy decoding chooses the most likely next token:

\[ \hat w_t = \arg\max_{v\in V} p_\theta(v\mid \hat w_{<t}). \]

Greedy decoding is deterministic. It is simple and often produces fluent text, but it can become repetitive and may miss globally better sequences. It is a local optimization rule, not a global maximum-likelihood sequence search.

22.10 17.9 Temperature scaling

Given logits \(z\in R^d\), temperature scaling defines

\[ p_j(\tau) = \frac{\exp(z_j/\tau)}{\sum_{\ell=1}^{d}\exp(z_\ell/\tau)}, \qquad \tau>0. \]

Small temperature sharpens the distribution. Large temperature flattens it. As \(\tau\to 0\), the distribution concentrates on the largest logit. As \(\tau\to \infty\), it approaches the uniform distribution.

Temperature does not change the ordering of logits, but it changes entropy. The entropy is

\[ H(p(\tau))=-\sum_{j=1}^{d}p_j(\tau)\log p_j(\tau). \]

In applications, temperature is a diversity-control parameter.

22.11 17.10 Top-\(k\) sampling

Top-\(k\) sampling keeps only the \(k\) highest-probability tokens. Let \(S_k\) be the set of \(k\) token indices with largest probabilities. The top-\(k\) distribution is

\[ q_j = \begin{cases} \dfrac{p_j}{\sum_{\ell\in S_k}p_\ell}, & j\in S_k,\\ 0, & j\notin S_k. \end{cases} \]

Then the next token is sampled from \(q\). Top-\(k\) sampling prevents extremely unlikely tokens from being selected while still allowing randomness among likely tokens.

22.12 17.11 Nucleus sampling, or top-\(p\) sampling

Nucleus sampling chooses the smallest set \(S_p\) of high-probability tokens whose cumulative probability is at least a threshold \(p_0\). After sorting probabilities in descending order,

\[ p_{(1)}\geq p_{(2)}\geq \cdots \geq p_{(d)}, \]

choose the smallest \(m\) such that

\[ \sum_{r=1}^{m}p_{(r)}\geq p_0. \]

The nucleus is

\[ S_p=\{(1),\ldots,(m)\}. \]

Then probabilities are renormalized on \(S_p\). Unlike top-\(k\), the number of allowed tokens changes with the confidence of the distribution. If the distribution is sharp, the nucleus may be small. If the distribution is flat, the nucleus may be larger.

22.13 17.12 Beam search

Beam search is an approximate search for a high-probability sequence. It maintains a set of \(B\) candidate prefixes called the beam. At each step, each candidate prefix is extended by possible next tokens, and only the \(B\) highest-scoring extended prefixes are kept.

The score of a sequence is usually its log-probability:

\[ s(w_{1:T}) = \sum_{t=1}^{T}\log p_\theta(w_t\mid w_{<t}). \]

Because log-probabilities are usually negative, longer sequences tend to have smaller scores. Some implementations use length normalization, for example

\[ s_\alpha(w_{1:T}) = \frac{1}{T^\alpha} \sum_{t=1}^{T}\log p_\theta(w_t\mid w_{<t}), \]

where \(\alpha\geq 0\).

Beam search is common in translation and structured generation, but for open-ended generation it can produce dull or repetitive text because it aggressively seeks high-probability continuations.

22.14 17.13 Worked example: likelihood and perplexity

Suppose a vocabulary contains four tokens:

\[ V=\{\texttt{math},\texttt{models},\texttt{learn},\texttt{data}\}. \]

A model assigns the following next-token probabilities to the observed sequence

math models learn data

at the four positions:

\[ 0.40,\quad 0.25,\quad 0.50,\quad 0.20. \]

The sequence probability is

\[ 0.40\cdot 0.25\cdot 0.50\cdot 0.20=0.01. \]

The log-probability is

\[ \log(0.01)\approx -4.6052. \]

The average negative log-likelihood is

\[ -\frac{1}{4}\log(0.01)\approx 1.1513. \]

The perplexity is

\[ \exp(1.1513)\approx 3.1623. \]

This means that, on average, the model behaves as if it were choosing among about \(3.16\) equally likely next-token options at each step.

22.15 17.14 Python example: softmax, likelihood, and perplexity

import numpy as np

np.set_printoptions(precision=4, suppress=True)

def softmax(logits, temperature=1.0):
    logits = np.asarray(logits, dtype=float) / temperature
    shifted = logits - np.max(logits)
    exp_scores = np.exp(shifted)
    return exp_scores / exp_scores.sum()

def sequence_log_probability(next_token_probabilities):
    probs = np.asarray(next_token_probabilities, dtype=float)
    if np.any(probs <= 0):
        raise ValueError("All observed-token probabilities must be positive.")
    return np.log(probs).sum()

def perplexity(next_token_probabilities):
    probs = np.asarray(next_token_probabilities, dtype=float)
    avg_nll = -np.log(probs).mean()
    return float(np.exp(avg_nll))

observed_probs = [0.40, 0.25, 0.50, 0.20]
logp = sequence_log_probability(observed_probs)
ppl = perplexity(observed_probs)

print("Sequence log-probability:", logp)
print("Perplexity:", ppl)

logits = np.array([2.0, 1.2, 0.5, -0.4])
print("Softmax probabilities:", softmax(logits))
print("Temperature 0.5:", softmax(logits, temperature=0.5))
print("Temperature 2.0:", softmax(logits, temperature=2.0))

22.17 17.16 Python example: decoding rules

rng = np.random.default_rng(7243)

vocab = np.array(["math", "models", "learn", "data", "language", "proof"])
base_logits = np.array([2.5, 2.0, 1.2, 0.7, 0.3, -0.8])

def top_k_filter(probs, k):
    probs = np.asarray(probs, dtype=float)
    if k >= len(probs):
        return probs / probs.sum()
    keep = np.argsort(probs)[::-1][:k]
    q = np.zeros_like(probs)
    q[keep] = probs[keep]
    return q / q.sum()

def top_p_filter(probs, p_threshold):
    probs = np.asarray(probs, dtype=float)
    order = np.argsort(probs)[::-1]
    cumulative = np.cumsum(probs[order])
    m = int(np.searchsorted(cumulative, p_threshold, side="left")) + 1
    keep = order[:m]
    q = np.zeros_like(probs)
    q[keep] = probs[keep]
    return q / q.sum()

p = softmax(base_logits, temperature=1.0)
print("Base distribution")
for token, prob in zip(vocab, p):
    print(f"{token:>9s}: {prob:.4f}")

print("\nTop-k distribution, k=3")
qk = top_k_filter(p, k=3)
for token, prob in zip(vocab, qk):
    print(f"{token:>9s}: {prob:.4f}")

print("\nTop-p distribution, p=0.80")
qp = top_p_filter(p, p_threshold=0.80)
for token, prob in zip(vocab, qp):
    print(f"{token:>9s}: {prob:.4f}")

sampled_token = rng.choice(vocab, p=qp)
print("\nSample from top-p distribution:", sampled_token)

22.18 17.17 Python example: a tiny autoregressive generator

The following example is intentionally simple. It uses a hand-built bigram-like table so that the mathematics of generation is visible.

rng = np.random.default_rng(2026)

vocab = ["<bos>", "math", "models", "learn", "from", "data", "language", "<eos>"]
idx = {w: i for i, w in enumerate(vocab)}

# Rows are contexts, columns are next-token logits.
Z = np.full((len(vocab), len(vocab)), -3.0)

def set_logits(context, scores):
    row = idx[context]
    for token, score in scores.items():
        Z[row, idx[token]] = score

set_logits("<bos>", {"math": 2.0, "language": 1.8, "models": 0.5})
set_logits("math", {"models": 2.5, "learn": 1.0, "data": 0.2})
set_logits("language", {"models": 2.4, "data": 0.4})
set_logits("models", {"learn": 2.2, "from": 1.4, "<eos>": 0.1})
set_logits("learn", {"from": 2.3, "data": 1.0})
set_logits("from", {"data": 2.6, "language": 0.4})
set_logits("data", {"<eos>": 2.2, "models": 0.4})
set_logits("<eos>", {"<eos>": 3.0})

def next_distribution(context_token, temperature=1.0, top_k=None, top_p=None):
    probs = softmax(Z[idx[context_token]], temperature=temperature)
    if top_k is not None:
        probs = top_k_filter(probs, top_k)
    if top_p is not None:
        probs = top_p_filter(probs, top_p)
    return probs

def generate(max_steps=10, temperature=1.0, top_k=None, top_p=None):
    tokens = ["<bos>"]
    for _ in range(max_steps):
        probs = next_distribution(tokens[-1], temperature=temperature, top_k=top_k, top_p=top_p)
        next_token = rng.choice(vocab, p=probs)
        tokens.append(next_token)
        if next_token == "<eos>":
            break
    return tokens

for temp in [0.5, 1.0, 1.8]:
    print(f"temperature={temp}:", " ".join(generate(temperature=temp, top_p=0.90)))

22.19 17.18 Python example: beam search

import math

def beam_search(beam_width=3, max_steps=6, alpha=0.0):
    beam = [(["<bos>"], 0.0)]
    completed = []

    for _ in range(max_steps):
        candidates = []
        for tokens, score in beam:
            if tokens[-1] == "<eos>":
                completed.append((tokens, score))
                candidates.append((tokens, score))
                continue
            probs = next_distribution(tokens[-1], temperature=1.0)
            for j, prob in enumerate(probs):
                if prob > 0:
                    new_tokens = tokens + [vocab[j]]
                    new_score = score + math.log(prob)
                    candidates.append((new_tokens, new_score))

        def normalized_score(item):
            tokens, score = item
            length = max(len(tokens) - 1, 1)
            return score / (length ** alpha)

        candidates.sort(key=normalized_score, reverse=True)
        beam = candidates[:beam_width]

    completed.extend(beam)
    completed.sort(key=lambda item: item[1] / (max(len(item[0]) - 1, 1) ** alpha), reverse=True)
    return completed[:beam_width]

for tokens, score in beam_search(beam_width=3, max_steps=6, alpha=0.6):
    print(f"score={score: .4f} |", " ".join(tokens))

22.22 17.21 AI-assisted learning activities

Use an AI assistant as a mathematical tutor, not as a black box. Good prompts force the assistant to state the conditioning, the probability distribution, and the loss function.

TipPrompt 1: identify the distribution

Ask:

In the sentence language models predict tokens, list the autoregressive training pairs. For each pair, identify the prefix, the target token, and the conditional probability that appears in the likelihood.

Then check whether the answer correctly distinguishes \(p(w_t\mid w_{<t})\) from \(p(w_{<t}\mid w_t)\).

TipPrompt 2: decoding audit

Ask:

Explain the difference between temperature, top-k sampling, and nucleus sampling using probability notation. Give one example where top-k and top-p keep different numbers of tokens.

Then verify the explanation by computing the filtered distributions yourself.

TipPrompt 3: perplexity interpretation

Ask:

22.23 17.22 Common mistakes

  1. Confusing the chain rule with a Markov assumption. The factorization \(P(w_{1:T})=\prod_t P(w_t\mid w_{<t})\) is exact. A Markov model makes the additional approximation \(P(w_t\mid w_{<t})\approx P(w_t\mid w_{t-r:t-1})\).

  2. Treating logits as probabilities. Logits can be any real numbers. Probabilities appear after softmax.

  3. Ignoring length in sequence scores. The raw log-probability of a sequence usually decreases as length increases. Comparing sequences of different lengths requires care.

  4. Believing sampling is the same as training. Training usually uses teacher forcing. Generation conditions on previously generated tokens.

  5. Thinking low perplexity guarantees high-quality answers. Perplexity is a likelihood metric. It does not by itself measure truthfulness, fairness, safety, or usefulness.

## 17.1 The basic object: a distribution on sequences

Let $V$ be a finite vocabulary with $|V|=d$.  A token sequence of length $T$ is

$$
w_{1:T} = (w_1,w_2,\ldots,w_T) \in V^T.
$$

A language model assigns probabilities to sequences.  For a fixed length $T$, this means a probability mass function

$$
P(w_{1:T}), \qquad w_{1:T} \in V^T,
$$

satisfying

$$
P(w_{1:T}) \geq 0, \qquad \sum_{w_{1:T} \in V^T} P(w_{1:T}) = 1.
$$

The space $V^T$ has size $d^T$, so directly specifying $P$ is impossible except for tiny vocabularies and tiny lengths.  The central mathematical idea is to factor the joint distribution into conditional distributions.

By the chain rule of probability,

$$
P(w_{1:T})
=
P(w_1)P(w_2 \mid w_1)P(w_3 \mid w_{1:2})\cdots P(w_T \mid w_{1:T-1}).
$$

Equivalently,

$$
P(w_{1:T})
=
\prod_{t=1}^{T} P(w_t \mid w_{<t}),
$$

where $w_{<t}=(w_1,\ldots,w_{t-1})$.  This identity is exact.  An autoregressive language model is a parameterized approximation of these conditional probabilities.

::: {.callout-note}
## Autoregressive viewpoint

An **autoregressive language model** estimates

$$
p_\theta(w_t \mid w_{<t})
$$

for each position $t$.  The model then defines a sequence distribution by

$$
p_\theta(w_{1:T})
=
\prod_{t=1}^{T} p_\theta(w_t \mid w_{<t}).
$$
:::

The word *autoregressive* means that the model generates each new token using previously generated tokens as input.  In time series notation, the future is predicted from the past.  In NLP notation, the next token is predicted from the prefix.

## 17.2 Prefixes, contexts, and conditional distributions

For every prefix $c=w_{<t}$, an autoregressive model outputs a probability vector

$$
p_\theta(\cdot \mid c) \in \Delta^{d-1},
$$

where

$$
\Delta^{d-1}
=
\left\{p\in R^d: p_j\geq 0,\; \sum_{j=1}^d p_j=1\right\}
$$

is the probability simplex.  If the vocabulary is ordered as

$$
V=\{v_1,\ldots,v_d\},
$$

then the model output is

$$
p_\theta(\cdot \mid c)
=
\left(p_\theta(v_1\mid c),\ldots,p_\theta(v_d\mid c)\right).
$$

A neural language model usually produces real-valued logits

$$
z_\theta(c) \in R^d,
$$

and converts them to probabilities by the softmax map

$$
p_\theta(v_j\mid c)
=
\frac{\exp(z_j(c))}{\sum_{\ell=1}^{d}\exp(z_\ell(c))}.
$$

The logits are scores.  The softmax turns scores into a categorical distribution.

::: {.callout-important}
## Representation, model, and probability

For a prefix $c$, a modern neural language model usually has the form

$$
c \longmapsto h_\theta(c) \in R^m
\longmapsto z_\theta(c)=Wh_\theta(c)+b \in R^d
\longmapsto p_\theta(\cdot\mid c)=\operatorname{softmax}(z_\theta(c)).
$$

The representation $h_\theta(c)$ is not itself a probability distribution.  The probability distribution appears after the output logits are transformed by softmax.
:::

## 17.3 Training data and maximum likelihood

Suppose the training corpus consists of token sequences

$$
D=\{w^{(i)}_{1:T_i}: i=1,\ldots,n\}.
$$

The likelihood of the data under an autoregressive model is

$$
L(\theta;D)
=
\prod_{i=1}^{n}\prod_{t=1}^{T_i}
p_\theta\left(w_t^{(i)} \mid w_{<t}^{(i)}\right).
$$

The log-likelihood is

$$
\ell(\theta;D)
=
\sum_{i=1}^{n}\sum_{t=1}^{T_i}
\log p_\theta\left(w_t^{(i)} \mid w_{<t}^{(i)}\right).
$$

Training usually minimizes the negative log-likelihood,

$$
\mathcal L(\theta)
=
-
\sum_{i=1}^{n}\sum_{t=1}^{T_i}
\log p_\theta\left(w_t^{(i)} \mid w_{<t}^{(i)}\right).
$$

This is also the sum of cross-entropy losses.  At each position $t$, the target is the one-hot vector for the observed next token.  If $y_t$ is the index of $w_t$, then the one-position loss is

$$
\ell_t(\theta)=-\log p_\theta(y_t\mid w_{<t}).
$$

For logits $z\in R^d$ and target class $y$, the gradient of the softmax cross-entropy is

$$
\frac{\partial}{\partial z_j}\left[-\log \operatorname{softmax}(z)_y\right]
=
\operatorname{softmax}(z)_j - 1\{j=y\}.
$$

This simple formula is one reason next-token prediction scales well computationally.

## 17.4 Teacher forcing

During training, the model is given the true prefix from the corpus.  For example, from the sentence

```text
language models predict the next token
```

we form training pairs:

```text
prefix: language                 target: models
prefix: language models          target: predict
prefix: language models predict  target: the
```

This training approach is called **teacher forcing**.  The model learns from correct prefixes even though, at generation time, it must condition on tokens that it generated itself.

Mathematically, training minimizes empirical conditional cross-entropy under the empirical distribution of true prefixes.  Generation samples from the model distribution over its own prefixes.  This mismatch is one source of error accumulation in generated text.

## 17.5 Sentence probability, average loss, and perplexity

For one sequence $w_{1:T}$, the model log-probability is

$$
\log p_\theta(w_{1:T})
=
\sum_{t=1}^{T}\log p_\theta(w_t\mid w_{<t}).
$$

The average negative log-likelihood per token is

$$
\bar{\mathcal L}
=
-
\frac{1}{T}
\sum_{t=1}^{T}\log p_\theta(w_t\mid w_{<t}).
$$

The perplexity is

$$
\operatorname{PPL}
=
\exp(\bar{\mathcal L}).
$$

Perplexity can be interpreted as an effective average number of plausible next-token choices.  Lower perplexity usually means the model assigns higher probability to the observed text, but perplexity is not a complete measure of usefulness or truthfulness.

::: {.callout-warning}
## Perplexity is not understanding

A model can have low perplexity on a dataset by learning strong statistical regularities.  This does not imply that it reasons correctly, uses facts reliably, or understands meaning in a human sense.  Perplexity is a likelihood-based metric, not a complete evaluation of language behavior.
:::

## 17.6 Decoder-only Transformers as autoregressive models

A decoder-only Transformer represents the prefix $w_{<t}$ using a stack of causal self-attention blocks.  If the input sequence is

$$
w_{1:T},
$$

then each position $t$ produces a hidden vector $h_t\in R^m$.  The output logits for the next token are often computed by

$$
z_t = Wh_t + b \in R^d,
$$

and the next-token distribution is

$$
p_\theta(w_{t+1}=v_j\mid w_{1:t})
=
\frac{\exp((z_t)_j)}{\sum_{\ell=1}^{d}\exp((z_t)_\ell)}.
$$

The causal mask ensures that the hidden vector at position $t$ cannot use tokens from positions greater than $t$.  Without causal masking, a language model trained to predict the next token could leak information from the future.

For a sequence length $T$, the causal attention mask has entries

$$
M_{ij}=
\begin{cases}
0, & j\leq i,\\
-\infty, & j>i.
\end{cases}
$$

The attention weights are computed as

$$
A=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}+M\right),
$$

where the softmax is applied row by row.

## 17.7 Generation as repeated sampling

Once a model produces $p_\theta(\cdot\mid c)$, generation repeats three steps:

1. Compute logits $z_\theta(c)$ for the current context $c$.
2. Convert logits to a probability distribution, possibly modified by a decoding rule.
3. Choose the next token and append it to the context.

This gives a recursive stochastic process:

$$
W_t \sim p_\theta(\cdot\mid W_{<t}),
\qquad t=1,2,\ldots.
$$

Different decoding rules define different stochastic or deterministic processes.

## 17.8 Greedy decoding

Greedy decoding chooses the most likely next token:

$$
\hat w_t
=
\arg\max_{v\in V} p_\theta(v\mid \hat w_{<t}).
$$

Greedy decoding is deterministic.  It is simple and often produces fluent text, but it can become repetitive and may miss globally better sequences.  It is a local optimization rule, not a global maximum-likelihood sequence search.

## 17.9 Temperature scaling

Given logits $z\in R^d$, temperature scaling defines

$$
p_j(\tau)
=
\frac{\exp(z_j/\tau)}{\sum_{\ell=1}^{d}\exp(z_\ell/\tau)},
\qquad \tau>0.
$$

Small temperature sharpens the distribution.  Large temperature flattens it.  As $\tau\to 0$, the distribution concentrates on the largest logit.  As $\tau\to \infty$, it approaches the uniform distribution.

Temperature does not change the ordering of logits, but it changes entropy.  The entropy is

$$
H(p(\tau))=-\sum_{j=1}^{d}p_j(\tau)\log p_j(\tau).
$$

In applications, temperature is a diversity-control parameter.

## 17.10 Top-$k$ sampling

Top-$k$ sampling keeps only the $k$ highest-probability tokens.  Let $S_k$ be the set of $k$ token indices with largest probabilities.  The top-$k$ distribution is

$$
q_j
=
\begin{cases}
\dfrac{p_j}{\sum_{\ell\in S_k}p_\ell}, & j\in S_k,\\
0, & j\notin S_k.
\end{cases}
$$

Then the next token is sampled from $q$.  Top-$k$ sampling prevents extremely unlikely tokens from being selected while still allowing randomness among likely tokens.

## 17.11 Nucleus sampling, or top-$p$ sampling

Nucleus sampling chooses the smallest set $S_p$ of high-probability tokens whose cumulative probability is at least a threshold $p_0$.  After sorting probabilities in descending order,

$$
p_{(1)}\geq p_{(2)}\geq \cdots \geq p_{(d)},
$$

choose the smallest $m$ such that

$$
\sum_{r=1}^{m}p_{(r)}\geq p_0.
$$

The nucleus is

$$
S_p=\{(1),\ldots,(m)\}.
$$

Then probabilities are renormalized on $S_p$.  Unlike top-$k$, the number of allowed tokens changes with the confidence of the distribution.  If the distribution is sharp, the nucleus may be small.  If the distribution is flat, the nucleus may be larger.

## 17.12 Beam search

Beam search is an approximate search for a high-probability sequence.  It maintains a set of $B$ candidate prefixes called the beam.  At each step, each candidate prefix is extended by possible next tokens, and only the $B$ highest-scoring extended prefixes are kept.

The score of a sequence is usually its log-probability:

$$
s(w_{1:T})
=
\sum_{t=1}^{T}\log p_\theta(w_t\mid w_{<t}).
$$

Because log-probabilities are usually negative, longer sequences tend to have smaller scores.  Some implementations use length normalization, for example

$$
s_\alpha(w_{1:T})
=
\frac{1}{T^\alpha}
\sum_{t=1}^{T}\log p_\theta(w_t\mid w_{<t}),
$$

where $\alpha\geq 0$.

Beam search is common in translation and structured generation, but for open-ended generation it can produce dull or repetitive text because it aggressively seeks high-probability continuations.

## 17.13 Worked example: likelihood and perplexity

Suppose a vocabulary contains four tokens:

$$
V=\{\texttt{math},\texttt{models},\texttt{learn},\texttt{data}\}.
$$

A model assigns the following next-token probabilities to the observed sequence

```text
math models learn data
```

at the four positions:

$$
0.40,\quad 0.25,\quad 0.50,\quad 0.20.
$$

The sequence probability is

$$
0.40\cdot 0.25\cdot 0.50\cdot 0.20=0.01.
$$

The log-probability is

$$
\log(0.01)\approx -4.6052.
$$

The average negative log-likelihood is

$$
-\frac{1}{4}\log(0.01)\approx 1.1513.
$$

The perplexity is

$$
\exp(1.1513)\approx 3.1623.
$$

This means that, on average, the model behaves as if it were choosing among about $3.16$ equally likely next-token options at each step.

## 17.14 Python example: softmax, likelihood, and perplexity

#| label: ch17-softmax-perplexity
#| echo: true

import numpy as np

np.set_printoptions(precision=4, suppress=True)

def softmax(logits, temperature=1.0):
    logits = np.asarray(logits, dtype=float) / temperature
    shifted = logits - np.max(logits)
    exp_scores = np.exp(shifted)
    return exp_scores / exp_scores.sum()

def sequence_log_probability(next_token_probabilities):
    probs = np.asarray(next_token_probabilities, dtype=float)
    if np.any(probs <= 0):
        raise ValueError("All observed-token probabilities must be positive.")
    return np.log(probs).sum()

def perplexity(next_token_probabilities):
    probs = np.asarray(next_token_probabilities, dtype=float)
    avg_nll = -np.log(probs).mean()
    return float(np.exp(avg_nll))

observed_probs = [0.40, 0.25, 0.50, 0.20]
logp = sequence_log_probability(observed_probs)
ppl = perplexity(observed_probs)

print("Sequence log-probability:", logp)
print("Perplexity:", ppl)

logits = np.array([2.0, 1.2, 0.5, -0.4])
print("Softmax probabilities:", softmax(logits))
print("Temperature 0.5:", softmax(logits, temperature=0.5))
print("Temperature 2.0:", softmax(logits, temperature=2.0))

## 17.16 Python example: decoding rules

```{python}
#| label: ch17-decoding-rules
#| echo: true

rng = np.random.default_rng(7243)

vocab = np.array(["math", "models", "learn", "data", "language", "proof"])
base_logits = np.array([2.5, 2.0, 1.2, 0.7, 0.3, -0.8])

def top_k_filter(probs, k):
    probs = np.asarray(probs, dtype=float)
    if k >= len(probs):
        return probs / probs.sum()
    keep = np.argsort(probs)[::-1][:k]
    q = np.zeros_like(probs)
    q[keep] = probs[keep]
    return q / q.sum()

def top_p_filter(probs, p_threshold):
    probs = np.asarray(probs, dtype=float)
    order = np.argsort(probs)[::-1]
    cumulative = np.cumsum(probs[order])
    m = int(np.searchsorted(cumulative, p_threshold, side="left")) + 1
    keep = order[:m]
    q = np.zeros_like(probs)
    q[keep] = probs[keep]
    return q / q.sum()

p = softmax(base_logits, temperature=1.0)
print("Base distribution")
for token, prob in zip(vocab, p):
    print(f"{token:>9s}: {prob:.4f}")

print("\nTop-k distribution, k=3")
qk = top_k_filter(p, k=3)
for token, prob in zip(vocab, qk):
    print(f"{token:>9s}: {prob:.4f}")

print("\nTop-p distribution, p=0.80")
qp = top_p_filter(p, p_threshold=0.80)
for token, prob in zip(vocab, qp):
    print(f"{token:>9s}: {prob:.4f}")

sampled_token = rng.choice(vocab, p=qp)
print("\nSample from top-p distribution:", sampled_token)
```

## 17.17 Python example: a tiny autoregressive generator

The following example is intentionally simple.  It uses a hand-built bigram-like table so that the mathematics of generation is visible.

```{python}
#| label: ch17-tiny-generator
#| echo: true

rng = np.random.default_rng(2026)

vocab = ["<bos>", "math", "models", "learn", "from", "data", "language", "<eos>"]
idx = {w: i for i, w in enumerate(vocab)}

# Rows are contexts, columns are next-token logits.
Z = np.full((len(vocab), len(vocab)), -3.0)

def set_logits(context, scores):
    row = idx[context]
    for token, score in scores.items():
        Z[row, idx[token]] = score

set_logits("<bos>", {"math": 2.0, "language": 1.8, "models": 0.5})
set_logits("math", {"models": 2.5, "learn": 1.0, "data": 0.2})
set_logits("language", {"models": 2.4, "data": 0.4})
set_logits("models", {"learn": 2.2, "from": 1.4, "<eos>": 0.1})
set_logits("learn", {"from": 2.3, "data": 1.0})
set_logits("from", {"data": 2.6, "language": 0.4})
set_logits("data", {"<eos>": 2.2, "models": 0.4})
set_logits("<eos>", {"<eos>": 3.0})

def next_distribution(context_token, temperature=1.0, top_k=None, top_p=None):
    probs = softmax(Z[idx[context_token]], temperature=temperature)
    if top_k is not None:
        probs = top_k_filter(probs, top_k)
    if top_p is not None:
        probs = top_p_filter(probs, top_p)
    return probs

def generate(max_steps=10, temperature=1.0, top_k=None, top_p=None):
    tokens = ["<bos>"]
    for _ in range(max_steps):
        probs = next_distribution(tokens[-1], temperature=temperature, top_k=top_k, top_p=top_p)
        next_token = rng.choice(vocab, p=probs)
        tokens.append(next_token)
        if next_token == "<eos>":
            break
    return tokens

for temp in [0.5, 1.0, 1.8]:
    print(f"temperature={temp}:", " ".join(generate(temperature=temp, top_p=0.90)))
```

## 17.18 Python example: beam search

```{python}
#| label: ch17-beam-search
#| echo: true

import math

def beam_search(beam_width=3, max_steps=6, alpha=0.0):
    beam = [(["<bos>"], 0.0)]
    completed = []

    for _ in range(max_steps):
        candidates = []
        for tokens, score in beam:
            if tokens[-1] == "<eos>":
                completed.append((tokens, score))
                candidates.append((tokens, score))
                continue
            probs = next_distribution(tokens[-1], temperature=1.0)
            for j, prob in enumerate(probs):
                if prob > 0:
                    new_tokens = tokens + [vocab[j]]
                    new_score = score + math.log(prob)
                    candidates.append((new_tokens, new_score))

        def normalized_score(item):
            tokens, score = item
            length = max(len(tokens) - 1, 1)
            return score / (length ** alpha)

        candidates.sort(key=normalized_score, reverse=True)
        beam = candidates[:beam_width]

    completed.extend(beam)
    completed.sort(key=lambda item: item[1] / (max(len(item[0]) - 1, 1) ** alpha), reverse=True)
    return completed[:beam_width]

for tokens, score in beam_search(beam_width=3, max_steps=6, alpha=0.6):
    print(f"score={score: .4f} |", " ".join(tokens))
```

    var scaled = logits.map(function(x){ return x / temperature; });
    var maxVal = Math.max.apply(null, scaled);
    var exps = scaled.map(function(x){ return Math.exp(x - maxVal); });
    var total = exps.reduce(function(a,b){ return a + b; }, 0);

  function topK(probs, k) {
    var pairs = probs.map(function(p, i){ return {p:p, i:i}; }).sort(function(a,b){ return b.p - a.p; });
    var keep = new Set(pairs.slice(0, k).map(function(x){ return x.i; }));
    var q = probs.map(function(p, i){ return keep.has(i) ? p : 0; });
    var total = q.reduce(function(a,b){ return a + b; }, 0);
    return q.map(function(x){ return total > 0 ? x / total : 0; });
  }

    var pairs = probs.map(function(p, i){ return {p:p, i:i}; }).sort(function(a,b){ return b.p - a.p; });
    var cumulative = 0;
    var keep = new Set();
    for (var r = 0; r < pairs.length; r++) {
      keep.add(pairs[r].i);
      cumulative += pairs[r].p;
      if (cumulative >= threshold) break;

    var total = q.reduce(function(a,b){ return a + b; }, 0);
    return q.map(function(x){ return total > 0 ? x / total : 0; });

## 17.22 Common mistakes

1. **Confusing the chain rule with a Markov assumption.**  The factorization $P(w_{1:T})=\prod_t P(w_t\mid w_{<t})$ is exact.  A Markov model makes the additional approximation $P(w_t\mid w_{<t})\approx P(w_t\mid w_{t-r:t-1})$.

2. **Treating logits as probabilities.**  Logits can be any real numbers.  Probabilities appear after softmax.

3. **Ignoring length in sequence scores.**  The raw log-probability of a sequence usually decreases as length increases.  Comparing sequences of different lengths requires care.

4. **Believing sampling is the same as training.**  Training usually uses teacher forcing.  Generation conditions on previously generated tokens.

5. **Thinking low perplexity guarantees high-quality answers.**  Perplexity is a likelihood metric.  It does not by itself measure truthfulness, fairness, safety, or usefulness.

## What to remember

- An autoregressive language model estimates $p_\theta(w_t\mid w_{<t})$.
- The sequence probability is the product of next-token conditional probabilities.
- Training usually minimizes next-token negative log-likelihood.
- Perplexity is the exponential of average negative log-likelihood.
- Generation is a recursive process in which sampled tokens become future context.
- Temperature, top-$k$, and top-$p$ modify the next-token distribution before sampling.
- Causal masking prevents a decoder-only model from seeing future tokens.
