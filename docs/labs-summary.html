31  Computer Labs

Google Colab Notebooks for Independent Study

The computer labs for Mathematical Foundations of Natural Language Processing are designed for independent study. Each lab begins with the necessary mathematical and conceptual background before programming, then develops the ideas through small transparent examples in Python.

The labs are stored in the labs/ folder of the GitHub repository:

https://github.com/wanghemath/Book-MathNLP

Each notebook can be opened directly in Google Colab. Students do not need to install Python locally, although the notebooks can also be downloaded and run in JupyterLab.

31.1 How to use the labs

A good workflow for each chapter is:

  1. read the corresponding textbook chapter;
  2. open the lab notebook in Google Colab;
  3. run the notebook from top to bottom once without changing code;
  4. return to each section and explain the mathematical idea in your own words;
  5. complete the exercises;
  6. complete the mini-project or extension task;
  7. write a short reflection on assumptions, limitations, and possible improvements.

The labs emphasize understanding before automation. Many examples intentionally use small toy corpora so that students can inspect the data, compute intermediate quantities by hand, and see how the mathematics becomes code.

31.2 Repository and Colab pattern

The general Colab link format is:

https://colab.research.google.com/github/wanghemath/Book-MathNLP/blob/main/labs/<notebook-name>.ipynb

31.5 Suggested grading or self-study structure

For a course, each lab can be used in one of three ways.

31.5.1 Option A. Guided practice

Students run the notebook, answer the short exercises, and submit selected outputs. This is appropriate for weekly low-stakes assignments.

31.5.2 Option B. Independent lab report

Students submit a short report containing:

  • a summary of the main mathematical idea;
  • one key equation and its interpretation;
  • selected code output;
  • answers to exercises;
  • one limitation or failure mode;
  • one proposed extension.

31.5.3 Option C. Mini-project pathway

Students use the mini-project section as a starting point for a longer project. This is appropriate for final projects, research preparation, or independent study.

31.6 Recommended pacing

A semester course can use the labs at different depths.

Course length Suggested use
7 weeks Labs 1–3, 5–6, 8, 13–15, 17, 19–20, 25
10 weeks Labs 1–10, 13–15, 17–20, 21–22, 25
14 weeks Labs 1–25, with selected mini-projects replacing some exercises

A slower mathematical course may spend more time on Labs 4, 7, 8, 13, 15, 21, and 22. A more applied NLP course may spend more time on Labs 6, 10, 17, 19, 20, and 25.

31.7 Technical notes

The labs are intended to run in Google Colab with common scientific Python libraries:

  • numpy
  • pandas
  • matplotlib
  • scikit-learn

Some notebooks use optional libraries when available, but the core examples are designed to remain small and transparent. The emphasis is on understanding the mathematical structure rather than training large models.

31.8 Student expectations

Students should keep the following principles in mind.

Tip

A lab is not complete when the code runs. A lab is complete when you can explain what mathematical object each variable represents and why the output makes sense.

For every model, ask:

  • What is the input space?
  • What is the output space?
  • What parameters are learned or chosen?
  • What loss, score, or criterion is being optimized?
  • What assumptions does the method make about language?
  • What failure modes should be checked?

31.9 Instructor notes

The labs can be used as weekly assignments, recitation materials, independent-study notebooks, or project preparation. Because each lab includes background before programming, students can also use them as review materials after completing the corresponding chapter.

When assigning labs, it is useful to ask students to submit both code output and written interpretation. The written interpretation helps students connect Python arrays back to the mathematical ideas in the textbook.
