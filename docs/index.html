Mathematical Foundations of Natural Language Processing

From Tokens and Probability to Transformers, Retrieval, and Responsible AI

Author

He Wang

Published

June 21, 2026

Natural language processing is the study of how language can be represented, modeled, learned, retrieved, generated, and evaluated by computational systems. This book develops NLP from a mathematical point of view, with enough Python computation to make the ideas concrete and testable.

This book is designed for students in applied mathematics, statistics, data science, computer science, and related quantitative programs who want to understand modern NLP beyond package usage. The central theme is that language data can be studied through familiar mathematical structures: finite sets, vectors, matrices, probability distributions, optimization problems, graphs, geometry, and topology.

0.1 What makes this book mathematical?

Rather than beginning with software libraries, the book begins with objects and operations.

NLP idea Mathematical viewpoint Computational object
Tokens Elements of a finite alphabet strings, integer ids
Documents Empirical measures or vectors token lists, count vectors
Vocabulary Finite set with indexing dictionaries, arrays
Language model Conditional probability distribution tables or neural networks
Embedding Map into a vector space dense matrix rows
Similarity Inner product, norm, or metric cosine score, distance matrix
Attention Similarity-weighted averaging operator query-key-value matrices
Transformer Nonlinear operator on sequences stacked attention and feedforward blocks
Retrieval Nearest-neighbor search in representation space ranked document lists
Evaluation Statistical estimation under uncertainty metrics, confidence intervals
Responsible NLP Error analysis across populations and contexts audits, calibration, bias diagnostics

The goal is not only to run an NLP model. The goal is to understand what the model is doing, what assumptions it makes, when it works, and how to diagnose its failures.

0.2 Intended audience

The book assumes basic familiarity with:

  • linear algebra: vectors, matrices, inner products, projections, eigenvalues, and singular value decomposition;
  • probability: conditional probability, likelihood, entropy, expectation, and random variables;
  • statistics: classification, estimation, empirical risk, validation, and uncertainty;
  • Python: NumPy, pandas, matplotlib, and basic machine learning workflows.

No prior NLP background is required. The computer labs are written for independent study and include the necessary background before programming begins.

0.3 How to use this book

Each chapter is organized around four layers.

  1. Conceptual layer: What is the NLP problem and why does it matter?
  2. Mathematical layer: What objects, maps, distributions, or optimization problems define the method?
  3. Computational layer: How can the idea be implemented in Python on a small transparent example?
  4. Critical layer: What can go wrong, and how should we evaluate or audit the method?

A recommended weekly workflow is:

  1. read the chapter overview and mathematical explanation;
  2. work through the examples by hand for a small toy corpus;
  3. open the corresponding lab in Google Colab;
  4. complete the guided exercises;
  5. write a short reflection on what the model assumes and where it may fail.

0.5 Mathematical spine of the course

A useful way to read the book is to follow the mathematical objects as they become more expressive.

text
  -> tokens
  -> count vectors
  -> probability distributions
  -> sparse and dense vector spaces
  -> neural sequence maps
  -> attention operators
  -> transformer blocks
  -> autoregressive probability models
  -> retrieval systems
  -> evaluated and audited NLP systems

The same mathematical ideas appear repeatedly:

  • Linearity: document-term matrices, embeddings, projections, attention scores, and low-rank adaptation.
  • Probability: likelihood, language modeling, entropy, calibration, decoding, and preference learning.
  • Optimization: cross-entropy minimization, stochastic gradients, AdamW, clipping, and regularization.
  • Geometry: similarity, clustering, anisotropy, hubness, positional encoding, and representation diagnostics.
  • Graphs: co-occurrence networks, dependency structures, knowledge graphs, message passing, and retrieval links.
  • Evaluation: metrics, uncertainty, subgroup analysis, factuality, robustness, and responsible deployment.

0.7 Suggested projects

Students can use the later chapters as starting points for final projects, for example:

  • compare TF-IDF, dense embeddings, and hybrid retrieval on a small course-document corpus;
  • audit a text classifier for subgroup performance and calibration;
  • build a transparent retrieval-augmented question-answering prototype;
  • study geometry and topology of sentence embeddings from different domains;
  • implement and evaluate decoding methods for a small autoregressive model;
  • compare graph-based and vector-based representations of language data.

See the Final Projects page for more ideas.
